Hero Cortina Interactivo

Componente Angular con efecto de revelación dual

✨ Características Principales

🎭 Efecto Cortina

Interacción horizontal suave que revela/oculta dos imágenes simultáneamente.

  • Mouse y touch compatible
  • Transiciones de 0.02s (60fps)
  • Divider visual con gradiente

🎨 Paleta Dual

Colores específicos para cada especialidad.

  • Cyan (#00D9FF) - Diseño Web
  • Magenta (#FF4D7D) - Diseño Gráfico
  • Modo claro/oscuro automático

📱 Responsive

Adapta el layout en todos los dispositivos.

  • Desktop: 2 columnas
  • Tablet: 1 columna ajustado
  • Móvil: Optimizado para pantallas pequeñas

♿ Accesibilidad

WCAG AA compliant con soporte para navegación.

  • ARIA labels en imágenes
  • Keyboard focus visible
  • prefers-reduced-motion soportado

⚡ Performance

Optimizado para velocidad y eficiencia.

  • Lazy loading de imágenes
  • CSS clip-path nativo
  • Sin librerías externas

🎬 Animaciones

Efectos visuales sutiles y profesionales.

  • Fondo animado (código flotante)
  • Gradientes en texto
  • Smooth hover effects

🚀 Integración Rápida

1. Importar el componente

import { HeroContainerComponent } from './hero-container/hero-container.component';

@Component({
  imports: [HeroContainerComponent]
})

2. Usar en el template

<app-hero-container></app-hero-container>

3. Personalizar colores (opcional)

:root {
  --accent-web: #tu-color-web;
  --accent-graphic: #tu-color-grafico;
}

📚 Próximos Pasos

1. Personalizar

Reemplaza las imágenes SVG con tus propios diseños y ajusta los textos según tu marca.

2. Probar

Prueba el componente en diferentes dispositivos y navegadores. Verifica el modo claro/oscuro.

3. Optimizar

Comprime las imágenes SVG y verifica las métricas de performance con Lighthouse.
